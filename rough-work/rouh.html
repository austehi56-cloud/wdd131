❔Why is the result variable value assigned '12' versus 3?

JavaScript performs implicit type coercion when you use the + operator with different types of values. In this case, you have a numeric value 1 and a string value '2'. When you try to concatenate a string with a number using the + operator, JavaScript converts the number to a string and performs string concatenation and not mathmatical addition.
